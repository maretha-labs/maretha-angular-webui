# Support

## Questions and ideas

Use [GitHub Discussions](https://github.com/maretha-labs/maretha-angular-webui/discussions) for questions, how-to help and ideas that are
not yet a confirmed bug or feature. Search first; someone may have asked already.

## Bugs and feature requests

Open an issue with the bug or feature form. Triage confirms it with the
`confirmed:bug` or `confirmed:feature` label; only confirmed work is merged. See
[CONTRIBUTING.md](CONTRIBUTING.md).

## Security problems

Never in public. Follow [SECURITY.md](SECURITY.md).

## Paid help

Maretha offers implementation, migration and support work around this project. Contact
[maretha@maretha.io](mailto:maretha@maretha.io).

## What this project does not support

- Nuxeo Platform or the stock Nuxeo Web UI themselves: those belong to Hyland.
- Code in your own `custom/` zone, beyond what the documentation and examples cover.
