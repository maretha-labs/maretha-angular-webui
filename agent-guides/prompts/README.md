# Prompts

Copy one into the agent's prompt, fill the angle-bracket fields, keep the acceptance line. Each
prompt assumes the agent reads [AGENTS.md](../../AGENTS.md) first.

- [add-contribution.md](add-contribution.md): one contribution to one slot.
- [add-layouts.md](add-layouts.md): the forms of one document type.
- [migrate-polymer.md](migrate-polymer.md): an existing Polymer customization into `custom/`.
- [contribute-upstream.md](contribute-upstream.md): a core change for a pull request.
