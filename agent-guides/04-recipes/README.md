# Recipes

One page per customization task: when it applies, the command, what to edit, and the file in the
ACME example ([examples/acme](../../examples/acme/README.md)) that does it. Every recipe ends with
`npm run verify`.

| Task                                                                           | Recipe                                                   |
| ------------------------------------------------------------------------------ | -------------------------------------------------------- |

| A button or notice in a toolbar, menu or bar                                   | [single-action.md](single-action.md)                     |
| A menu entry with a page: administration, analytics, publishing, create dialog | [paired-menu-and-page.md](paired-menu-and-page.md)       |
| A tab on the document page                                                     | [document-view.md](document-view.md)                     |
| A theme                                                                        | [theme.md](theme.md)                                     |

| Labels in several languages                                                    | [i18n.md](i18n.md)                                       |
| Labels from a Nuxeo Studio project (types, fields, vocabularies)               | [i18n.md](i18n.md#nuxeo-studio-translations)             |
| Showing, hiding, moving or replacing contributions                             | [visibility.md](visibility.md)                           |
| Result cards and cells; exports over the complete query                        | [projections-and-exports.md](projections-and-exports.md) |
