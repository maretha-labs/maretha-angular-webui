`RepositorySearchComponent` mounts the fallback renderer for table/list/grid results. `GenericFolderishViewerComponent` mounts the same host in table or grid mode; its grid card is an `item` template after Polymer's `nuxeo-document-grid-thumbnail`. `contextEpoch` prevents callbacks saved from an older row object from changing a replacement result set. The focused local Karma suite additionally covers keyboard selection, child-control isolation, disabled rows, readonly guards, fallback and two simultaneous instances.

Compiled search definitions can pass a view's lazy `components` map to this host: `item` replaces a grid card or list row, and `cell:<columnId>` replaces one table cell. Registered projections take precedence over definition components, which take precedence over stock templates. Imports are cached per host; changing views or destroying the host invalidates pending results. An import error reaches Angular's `ErrorHandler` and keeps the stock renderer available.

Search hosts supply `searchId` while retaining their established `hostId`. Both row and whole-result contexts carry the search ID, and `provideResultsProjections({ searchId: 'expired', ... })` restricts an add-on to that search. Row components also receive the guarded `activateRow()` callback. `results-projection-components.spec.ts` covers loading, view replacement, error fallback, column and add-on precedence, search isolation, and stale-context guards.
